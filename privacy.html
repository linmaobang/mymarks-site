MyMarks 隐私政策

生效日期：2026 年 10 月 29 日

简要说明
  • 你的地点记录、照片和笔记只保存在你自己的设备上。MyMarks 没有自己的服务器，也没有账号系统。
  • 我们不收集分析数据，不做广告追踪，也不出售任何数据。
  • 只有在你主动开启并配置后，部分内容才会发送给你自己选择的第三方服务（AI 服务、高德地图）。

1. 存在你设备上的数据

你在 MyMarks 中创建的地点记录（名称、类别、坐标、评分、标签、小结、到访笔记）和照片，保存在 App 的本地存储中。你填写的 API Key 保存在系统钥匙串（Keychain）中。这些数据不会上传到 MyMarks 开发者的任何服务器。

删除 App 会同时删除这些数据。你可以随时在「我的 → 备份手账」中把记录导出为 JSON 和 Markdown 文件。

2. 系统权限及用途

权限用途
位置在你使用 App 时获取当前位置，用来记录地点、显示附近的店铺。不会在后台持续定位。
相机 / 照片拍摄或选择招牌、菜单、收据的照片，在设备上用 Apple Vision 识别文字（OCR）。照片本身不会上传。
麦克风 / 语音识别把你说的话转写成文字记录。语音转写由 Apple 的语音识别服务完成，音频可能会发送到 Apple 处理，适用 Apple 隐私政策。

你可以随时在 iOS「设置」中关闭任何权限，关闭后对应功能不可用，其余功能照常。

3. 发送给第三方服务的数据

AI 服务（可选，默认关闭）。当你在「我的 → AI 助理」中填写自己的 API Key，并在「隐私与数据」中允许发送后，使用智能整理、回顾、问答、推荐、行程和语义搜索时，相关的地点名称、地址、评分、标签、小结和笔记会直接从你的设备发送到你选择的 AI 服务（例如 DeepSeek、OpenAI 或其他兼容服务）。这些数据由该服务按其自己的隐私政策处理，不经过 MyMarks 的服务器。关闭授权后 AI 功能不可用，其余功能照常。

地图与附近地点。地图显示和地点查询使用 Apple 地图（MapKit），适用 Apple 隐私政策。在中国大陆范围内，如果启用了高德 Web 服务，查询附近店铺时会把所在位置的坐标发送给高德地图（高德隐私政策）。

4. 我们不做的事

  • 不收集设备标识符、使用统计或崩溃日志。
  • 不接入广告或第三方追踪 SDK，不跨 App 或网站追踪你。
  • 不出售、出租或共享你的个人信息。

5. 儿童隐私

MyMarks 不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

6. 政策更新

如果本政策有实质变化，我们会更新本页面的生效日期，并在 App 更新说明中提示。
