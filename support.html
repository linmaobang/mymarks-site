MyMarks 支持

MyMarks 是一本私人的地点手账：走到哪，记到哪。

遇到问题或有建议，请发邮件至 linmaobang@gmail.com，通常会在 3 个工作日内回复。

AI 功能为什么用不了？

助手、回顾和语义搜索需要你自己的 AI 服务。在「我的 → AI 助理」中选择服务商（如 DeepSeek）并填写 API Key，再到「隐私与数据」中允许发送即可。不配置时，记录、地图和手账功能都能正常使用。

附近没有识别出店铺？

请确认已允许 MyMarks 使用位置，并处在网络良好的地方。识别不到时，可以手动输入店名记录。

怎么备份或换手机？

在「我的 → 备份手账」导出 JSON 文件，在新手机上导入即可。所有数据只存在你的设备上，删除 App 前请先导出。
